What I read

The Expo app in fittrack-mobile: 10 screens, theme/colors.ts, the tab navigator and the FT lettermark. Every colour, radius, font size and spacing value below is lifted from those files — nothing is from memory.

Current design system

One accent (acid lime) doing every job: CTA, active tab, icon tint, chart line, progress fill. Type is system SF at 800 weight for titles, 10–14px everywhere else. Radii 8–20. Borders on everything.

Why it reads as bland
  1. Every element is the same bordered dark card — no hierarchy, no rhythm.
  2. Type has one voice: dense small sans. Nothing is allowed to be big.
  3. Numbers without trends. 183 lbs means nothing without the line.
  4. Lime on charcoal on 10px grey — no warmth, no imagery, no daylight.
  5. 6 tabs, no primary action. The app never tells you what to do next.

09Stats — analytics
To fix in redesign
"Overview" is a spreadsheet of raw weigh-ins — the noisiest possible view of the noisiest possible metric, and no chart anywhere despite Recharts being in the stack. Overview should answer "am I on track?" at a glance: trend line vs scale dots (MacroFactor-style, weekly average smoothing), rate of change in lbs/week against goal, adherence (workouts done vs planned, days logged), and strength trend on the main lifts.
